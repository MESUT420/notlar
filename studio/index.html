Yazma masası

GitHub deposuna bağlan, yaz ve yayınla.

Erişim anahtarı nasıl oluşturulur?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → notlar. “Public repositories (read-only)” yazma izni vermez.
  3. Permissions → Repository permissions → Add permissions → Contents → Read and write. Metadata otomatik gelir.
  4. Generate token → anahtarı kopyala ve buraya yapıştır.

Contents seçeneğini göremiyorsan klasik token da çalışır: Tokens (classic) → Generate new token → repo kutusunu işaretle. Bu anahtar daha geniştir; işin bitince iptal edebilirsin.
